launches. Reconcile all relevant numeric shards and provider state, reserve concurrent

waiting for a human decision. An uncertain termination takes precedence over other work.

The user has already authorized experiments inside the unchanged total cap, so no
per-run permission question is needed. A lack of accepted production quality does not
stop research, fixture-based infrastructure, diagnostic planning or hub work. Never
