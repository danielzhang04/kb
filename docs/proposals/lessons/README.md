# Lesson proposal intake

`py -3 -m scripts.brain.session_miner mine <transcript.jsonl>` writes one reviewable markdown file here. Each file is `status: PROPOSED` and contains candidate `ADD` lessons with confidence and transcript-line evidence.

This is deliberately outside `memory/`: the miner has a mechanical refusal for memory paths. `scripts/dream.py` presently consolidates only existing `memory/*.md` entries and reserves `ADD` for a future trusted apply path. These files are that documented future intake seam; a human or that trusted path must judge and accept any candidate before it reaches memory.
