## Concrete mechanism
A three-loop agent-orchestration system: Foundation (research + plan, produces an approved PRD with task breakdown/wave plan/dependencies via a 5-round interview process), Decomposition (turns the PRD into task briefs + a brief-reviewer agent that challenges each brief for risks/conflicts before execution), Orchestration (a PM agent dispatches tasks in configured integration cadence — worktree, wave, or feature — gates between waves enforce quality, auto-pauses when reviews are green or skip entries are dirty, auto-merges once all gates pass). Model routing is complexity-based (Sonnet for simple tasks, Opus for complex ones per the Git Timeline notes panel). Context is deliberately staged (progressive disclosure + compression) rather than loaded flat into one session.
