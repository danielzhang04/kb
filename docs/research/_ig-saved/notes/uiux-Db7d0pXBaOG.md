## Steal-worthy patterns
1. **Radial/constellation agent graph as a primary navigation surface** — core knowledge node in the center, department ring, agent/skill leaf ring, all connected by lines; click a ring node to re-center and drill in, with breadcrumb + pager (`< Back 1/7 Sales >`) at the bottom. A genuinely different (and arguably richer) alternative to a flat org-chart tree for visualizing a large fleet — worth prototyping for kb's agent/skill map.
2. **Autonomy-ladder inside every workflow's detail panel** ("THE LADDER": Human-led / Human-assisted / Fully autonomous, each with a one-line description specific to that workflow) — this is a precise, reusable pattern for kb's own per-card or per-skill autonomy tier documentation (risk-tiers.md made visual, per-workflow instead of global).
3. **Slide-in right-panel detail view instead of full navigation** when clicking a graph node — preserves the graph context while inspecting one item.
4. **"WHAT IT REPLACES" field** — names the manual process being automated, in one sentence, on every workflow card. Cheap, high-value context for anyone auditing what an agent actually does.
5. **"THE SOP, WRITTEN OUT" numbered steps + "TOOLS AT THE END OF THE CHAIN" chip row** at the bottom of a workflow detail panel — a consistent closing block that always answers "what exactly happens, and with what tools."
6. **Persona/variant gallery** — the same dashboard shell reskinned per vertical/tenant, paged 1-of-N, each with its own North Star metric, pillars, connectors, and tracked metrics. Useful if kb ever needs to present per-org (`orgs/<project>/`) dashboards as variants of one shared shell.
7. **Funnel-as-connected-bubble-chain** (stage name + count + % retained, sized bubbles on a single horizontal line, color-coded lifecycle states) — a compact way to show a pipeline's attrition that's more visual than a table; could apply to kb's queue/card pipeline (queued -> claimed -> in-progress -> verified -> done) or FYT's gated pipeline stages.
8. **"NORTH STAR" single-metric callout, bolded, isolated from the metric list below it** — forces every dashboard/persona to declare the one number that matters before listing everything else it tracks.
