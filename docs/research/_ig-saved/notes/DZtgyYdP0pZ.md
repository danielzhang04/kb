## Concrete mechanism
Three MCP servers chained through one Claude session: Parallel MCP for lead-list generation/enrichment (scrape + JSON-schema enrichment task against a lead list), Perplexity Pro (used manually, not via MCP in this clip) for a structured deep-research SOP on 2026 cold-email best practices, and Instantly MCP (connected via a custom connector pointing at `https://mcp.instantly.ai/mcp/YOUR_API_KEY`) to let Claude write and directly create/configure a live multi-touch campaign inside Instantly, using the enriched lead data and the Perplexity SOP as inputs to the email copy and cadence.
