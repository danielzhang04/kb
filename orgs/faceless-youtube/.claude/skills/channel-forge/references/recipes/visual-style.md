# Recipe: visual-style stage

The locked look. **Gather** niche + doctrine + pipeline constraints + reference channels. **Reuse-first:** an
existing style-bible's structure, not a look. **Generate** 2-3 directions in an Artifact (image-generation),
**self-critique** vs. register + no-slop + differentiation, converge, present. **Gate:** human locks ONE →
visual-kit/style-bible.md + canonical refs. This is a high-stakes stage: use a larger critic panel.
