# Recipe: backlog stage

Seed the channel's first ranked ideas (the walk's final stage). **Gather** the finished channel dna. **Reuse-first:**
route to idea-generator (it reads the new dna.md). **Generate** a ranked backlog; **self-critique** vs. niche-fit +
differentiation + payload-first; present. **Gate:** the human picks the first video → genesis complete, hand off to
the production pipeline (researcher / long-form-writer / ...).
