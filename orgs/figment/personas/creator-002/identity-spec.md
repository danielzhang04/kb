# creator-002 — identity spec (fixture)

Second figment persona fixture, built to prove the pipeline (`figment_train.py` +
`pipeline/persona.py`) runs unchanged for a creator that is not creator-001 (P2 plan
task E1, creator-002 proof). This is a data-only fixture, not a live production
persona: `identity.references` currently point at three SYNTHETIC placeholder anchor
images (`anchors/*.jpg`, generated by `anchors/make_placeholders.py`), never a real
photograph of a real person. Replace them with a real anchor shoot and re-run
`figment_train.py plan --creator creator-002 --stage anchor` before this persona is
ever planned against a live pod.

## Face

An adult woman in her mid-twenties. Chestnut-brown wavy hair worn loose past the
shoulders. Hazel eyes, light-olive skin with visible pores and a scatter of freckles
across the nose and cheeks. Her own full brows, unshaped beyond daily grooming.

## Body

An ordinary adult figure, average build, no exaggeration in either direction. Hands
and neck read the same age as the face.

## Wardrobe register

Default register: a plain grey crew-neck sweatshirt and black leggings, both fully
opaque and intact — see `persona.yaml`'s `identity.look.clothing` for the exact
machine-read words. Wardrobe families for the expansion grammar are recorded in
`persona.yaml`'s `grammar.wardrobe_families`, deliberately reusing the same family
names as creator-001 (the families are wardrobe *categories*, not creator-specific
garments) while the front-matter clothing description stays this persona's own.

## Rule for expansion

Same rule as creator-001 (`orgs/figment/personas/creator-001/identity-spec.md`):
every cell the expansion grammar enumerates must keep this face and this body
readable and unchanged — angle, distance and light vary; identity does not.
