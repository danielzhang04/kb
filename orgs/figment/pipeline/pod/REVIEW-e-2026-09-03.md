- **Termination on every new exit path.** Upload/marker/download failures, `KeyboardInterrupt`, `RunCancelled`,
  watchdog fire, create failure, and finalization failures all reach `lease.close()` (either through
  `with ... lease:` at 2705, the `placement_needs_close` branch at 2889, or the `atexit` callback registered at
  2459 before the create POST). `run_harness` re-raises `PodStillRunning` at 2954 when verification did not happen,
  `command_run` re-checks at 2995, and `main.report` prints the `POD STILL RUNNING` banner (3140-3157). Guardrail 6 holds.
- **Credential handling (guardrail 5).** `RUNPOD_API_KEY` is read exactly once into `Session.headers` (200), the
  `ApiKeyRedactionFilter` reads it back out of the session rather than keeping a copy (147-163), `create_payload`
  ships no credential to the pod (the only `env` entry is the base64 bootstrap, 1600), `redact_pod_state` blanks any
  `env` dict and any key ending in `apikey`/`token`/`secret` (60-86), `run.json` is redacted on write (2381-2386),
  both proxy sessions set `trust_env = False` (1971, 198), and `ComfyClient` refuses any session carrying an
  `Authorization` header (1972-1976). The rendered training script and the bootstrap contain no secrets: model
  downloads are anonymous public HF URLs (1903) and no HF token is ever plumbed through.
- **Upload path traversal.** `_portable_relative_path` (980-988) rejects absolute paths, `..`, `.`, NULs, and
  Windows drive letters; every glob match is `resolve()`d (following symlinks) and re-checked with
  `is_relative_to(root)` (1064-1065); directories are rejected (1066-1067). `_safe_remote_subfolder` applies the
  same rules to the remote side. I could not construct an escape.
- **`/upload/image` wire contract.** Multipart field `image`, form fields `subfolder`/`type=input`/lowercase
  `overwrite`, 2xx-plus-matching-JSON requirement (2023-2061) match ComfyUI's `image_upload` handler and
  `HARNESS-CHANGES.md:14-18`.
- **Artifact `local` containment.** `out_dir.joinpath(*local_relative.parts)` (2772) over a `_portable_relative_path`
  -validated value cannot escape `out_dir`.
- **Ordering.** Uploads run after `wait_ready` + the READY-price/daily/arc re-checks and before both the artifact
  wait and any job submission (2725-2769); the start script is written in bootstrap before
  `comfyui.start_command` (1940-1946). Matches `HARNESS-CHANGES.md:14,19,23`.
- **Cost basis.** `settled_cost_estimate` (1558-1575) books elapsed × READY rate on a verified teardown, elapsed ×
  manifest ceiling rate when no READY price was ever seen, and `max(preflight, measured)` when teardown is
  unverified. Early failures are not inflated to the ceiling. Finding 2 is the one place this is undone.
- **Arc/daily guards.** Re-checked at the READY price (2730-2738) and before every placement recreate (2594-2609)
  with `avoided_cost_total` folded in.

## Summary (10 lines)

1. Baseline is green once pytest's basetemp is moved out of the repo: 119/119 pod, 4/4 train. As documented it reads 38/81 (finding 1).
2. No blockers. Termination-and-verify holds on every new exit path I traced, including the watchdog, signals, and mid-upload/mid-download failures.
