## Work order

[MEDIUM] Drain findings F10/R17 (P3 rehearsal): the admission alarm and the drain validator
disagree about what counts as a problem. `outboxStatus.ts:111` counts only `ready/*.json` files
when deciding whether admission is healthy, so an orphaned `.bundle` file (present without its
paired ready-json) is invisible to the admission alarm — but it is fatal to
`validate_snapshot` on the drain/reconcile path, which discovers it later and fails there
instead.

Fix: make admission status report `invalid` (not silently healthy) when it finds an unpaired
artifact — a `.bundle` without its `ready/*.json`, or vice versa — so the alarm surfaces the
problem at the point of admission instead of it only being caught during drain.

## Acceptance
- `outboxStatus.ts` (or wherever admission status is computed) detects unpaired
  `.bundle`/`ready/*.json` artifacts and reports `invalid`.
- Test: an orphaned `.bundle` with no matching `ready/*.json` placed in the outbox is caught by
  admission status, not only by `validate_snapshot`.
- Existing admission/outbox tests stay green.
