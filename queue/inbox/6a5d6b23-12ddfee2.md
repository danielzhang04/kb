## Work order

ONE-TIME human setup (integrations design D16, gate G1). In console.cloud.google.com:
1. Create/select a project (suggested name: kb-workspace).
2. Enable FIVE APIs (APIs & Services > Library): Gmail API, Google Drive API, Google Calendar
   API, YouTube Data API v3, YouTube Analytics API.
3. OAuth consent screen: User type External; add your own Google account as a Test user.
4. CRITICAL: after creating the OAuth client (gate G2 uses it), set the consent screen to
   'In production' (Publish app). In Testing mode Google EXPIRES refresh tokens after 7 days
   for sensitive scopes - headless workers would silently die weekly. Publishing a personal
   single-user app requires NO Google verification; you just click through the 'unverified
   app' warning once at consent.
5. Create OAuth client: type 'Desktop app'; note client ID + secret for gate G2 (do NOT paste
   them into any card or chat - set them as env vars per G2).
