\## Round-2 findings (address all 28)

1. CRITICAL — Boot reconciliation covers only `swapping`; a deployment stranded in
   requested/parked/resuming fences the control plane permanently (no daemon-side
   deadlineAt timer — the 35-min deadline is enforced by the deploy caller, which may
   be dead; normalizeCrash knows nothing of deployments; surfacing is only an opaque
   409). Fix: boot reconciliation total over DeploymentState (explicit rule per state,
   assertNever); deadlineAt re-armed as a daemon-side timer at every boot that aborts+
   unparks on expiry and files an Inbox intervention.
2. CRITICAL — No single-writer enforcement on the control document, and §2.3 designs
   for two live daemons (old daemon applies the mismatch rule while the new one claims
   resumes; resume token `resume:<deploymentRef>:<runRef>` is constant across
   processes so both claim "idempotently" → double execution/spend; TimeoutStopSec=90
   + KillMode=control-group lets stop overlap start; grep proves zero flock/lockfile/
   pidfile in dashboard/server). Fix: exclusive OS lock on DASHBOARD_STATE_ROOT/
   control/ held for process lifetime; refuse boot + fail /readyz if held; resume
   claims process-unique (<deploymentRef>:<bootId>) so a second claimant is detected,
   not deduped.
3. CRITICAL — Migrated-store/old-code rollback is a one-way door and the SIGKILL
   recovery oneshot has no per-phase behavior (up-migration runs before swap; old
   code's assertDocument hard-rejects version!==1 ([cutover] store.ts:2196-2198,
   :6534); Restart=on-failure won't restart a cleanly-stopped unit). Fix: publish an
   explicit phase → recovery-action table including snapshot restore at migrated/
   current-swapped; snapshot restore is the recovery oneshot's FIRST duty at any
   post-service-stopped phase.
4. HIGH — §2.2's residual-activity policy is inverted vs the binding ruling (see
   FIRST block above). Rewrite to encode: git-active + unknown children → bounded
   wait then refuse; pty/composer → refuse; state the wait bound.
5. HIGH — "paused-for-deploy becomes a compiler obligation" is not achieved: RunState

   return false (the exact run-silently-lost mode). Fix: make the change type-breaking
   (rename the field or brand RunState) + a test asserting every predicate/projection
   handles the new member; drop the manual-audit language.
6. HIGH — PID classifier needs PID data that doesn't exist (asyncGit.ts:138-159,
