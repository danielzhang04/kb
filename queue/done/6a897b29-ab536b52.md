Verdict: **FIX — not merge-ready.**

1. **HIGH — scheduled cards can run without a live claim receipt.**  
   `dashboard/server/control/queueBridge.ts:661-683,274-289` only refuses when the resolver itself is absent. If the live resolver returns `null`, resolution falls back to `workflow-def` or card owner; `queueBridge.test.ts:110-116` explicitly ratifies that fallback.  
   **Exact fix:** for cards carrying `scheduled_for`, resolve once and require a non-null receipt before mapping or proposal creation. Use only the receipt as authority; treat workflow/card owners solely as equality assertions. Add a production-wiring test where the resolver returns `null`, expecting `runnable-owner-required` and no proposal/Run.

2. **HIGH — schedule mutations are not operator-only at the authorization boundary.**  
   `dashboard/server/index.ts:213-253` applies generic `requireSession`; `dashboard/server/http/middleware.ts:125-140` accepts any verified subject, while `dashboard/server/auth/session.ts:140-183` permits arbitrary string `sub`. Thus a valid daemon/host-subject token satisfies the mutation gate. Existing coverage at `dashboard/server/index.test.ts:222-228` checks only missing credentials.  
   **Exact fix:** add a mutation-only pre-handler requiring `claims.sub === OPERATOR_SUBJECT`, returning 403 otherwise; keep GET session-readable. Add daemon and host bearer tests for create/arm/disarm/delete.

3. **HIGH — `GET /api/schedules` violates the exact public response contract.**  
   The contract is `{scheduleCollectionRevision,rows}` at `docs/plans/2026-08-21-dv3-p2-plan.md:368`; `dashboard/server/schedules/service.ts:331-340` exposes internal `{collectionRevision,schedules}`, and `dashboard/src/lib/scheduleClient.ts:81-88` depends on that wrong shape.  
   **Exact fix:** translate the REST response to `{scheduleCollectionRevision: snapshot.collectionRevision, rows: snapshot.schedules}` and update the client/UI/tests. Retain `{collectionRevision,schedules}` only on the internal socket protocol.

4. **HIGH — arm/disarm/delete emit no schedule event.**
