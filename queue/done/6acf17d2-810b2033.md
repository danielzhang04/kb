## Result

\## Ruling

**REQUEST CHANGES / operational BLOCK.** The narrow recovery design is sound in principle, but it is not yet proven or implemented in the reviewed script.

The evidence supports the core idea:

- A protected, disposable parent reproducing the original home inheritable DACL allowed ordinary `Set-Acl` to restore the pilot root with exact SDDL, including `AI`.
- The source and real home ACL remained unchanged.
- Same-volume forward and inverse renames preserved the descriptor, original data, and a post-cutover addition.

However, [pilot-recovery.ps1](<C:/Users/danie/Projects/Filesystem-Cleanup/scripts/pilot-recovery.ps1:125>) still contains the rejected native `SetKernelObjectSecurity` implementation, and its restore path still describes future inheritance as unknown at [line 348](<C:/Users/danie/Projects/Filesystem-Cleanup/scripts/pilot-recovery.ps1:348>). This review therefore **does not accept any current or concurrent code revision**.

\## Required contract

Accept the implementation only if it:

1. Captures the source root descriptor and the original parent’s inheritance-relevant DACL as immutable recovery metadata.
2. Creates a new, empty, protected envelope exclusively beneath the recovery/fixture destination.
3. Reproduces only the original parent’s inheritance-relevant ACE projection, plus any minimal non-inheritable ACE required to administer the envelope.
4. Creates the pilot root beneath that envelope and uses standard `Set-Acl` to restore its owner, group, and DACL.
5. Requires exact source-versus-restored owner/group/DACL SDDL, `P`/`AI`, ACE order, masks, inheritance flags, and `IsInherited` state.
6. Blocks on any parent-baseline or source-manifest mismatch. No stale-inheritance fallback, weakened comparison, native-helper retry, or arbitrary-parent restore.
7. Never changes the real source or original home ACL.

\## Mandatory disposable tests

- **Complete recovery:** For the root and all six files, compare entry set/type, SHA-256, length, attributes, creation/write times, stream inventory, hard-link count, owner/group, DACL SDDL, `P`/`AI`, ACE order and inherited markings across source A, source B, payload, and drill. Last-access time should remain informational because inspection changes it.
- **Wrong parent:** Modify, omit, reorder, or add one inheritable envelope ACE. Recovery must block before acceptance; an exact child mismatch must never be downgraded.
- **Source mutation:** Independently mutate file bytes, timestamps, root DACL, and one file DACL between A/copy/B. Each case must fail closed and preserve artifacts.
- **Future inheritance:** On synthetic control and restored trees, add and then remove a unique inheritable parent ACE. Compare existing root/descendant propagation, children created before and after each transition, and final restored descriptors. Exact behavior must match.
- **Rollback with additions:** After forward rename, add both a file and a nested directory/file with distinct content and metadata. Inverse rename must preserve identities, hashes, descriptors, and additions; an occupied old path must block without overlaying either tree.
- **Negative stale case:** A child carrying inherited ACEs from a former parent must be rejected unless the captured original-parent envelope reproduces an exact descriptor.

Do not generalize this into support for arbitrary trees, stale inherited ACL repair, inheritance toggling, or universal backup semantics. Those are unnecessary for this six-file pilot.

\## Least privilege and custody

The envelope does not require changing the real home ACL or granting broader rights than the original child had. It should run as the owning user; elevation is not part of this contract.

Copying the parent’s inheritance model creates a second live data copy accessible to the same inherited principals. That is an intentional custody expansion in location and retention, even if permissions are not broader. Keep the envelope protected, local, uniquely named, collision-refusing, outside synchronization targets, and recorded for later human-approved retirement. Never copy SACL privileges or unrelated non-inheritable home ACEs merely to imitate the whole home descriptor.

The elevated report establishes that the seven current objects had empty SACLs; it does not establish that they remain empty indefinitely. Treat it as dated evidence, not a universal omission rule.

Reviewed artifacts were read-only; no source copies, moves, ACL changes, delegation, commits, or external research were performed.
