   Trigger: a patch fails after one or more documents were written; the leases are released before rollback, and another writer changes a document between rollback’s precheck and sequential undo.

   Outcome: earlier documents can be restored while a later document is preserved as changed, leaving a mixed memory state. The directory remains moved, but the promised all-memory exclusive transaction boundary has been lost.

   Minimal contract correction: while all six original handles remain held, either restore every written document through those handles and verify the complete six-document state before reversing the rename, or preserve the partial moved state and stop. Never begin rollback after releasing or reacquiring the memory handles.

   Required test: block a competing writer during injected partial failure and prove it cannot acquire any memory file until rollback has completed or the operation has definitively chosen preservation.

Reject reports whose capture interval overlaps neither the final recovery capture nor the frozen window.
