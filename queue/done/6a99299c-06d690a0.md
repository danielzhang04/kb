2. **Task 7A, Step 3 — draft campaigns can be activated directly.** The status branch accepts `active` without requiring current `approved` status or a valid approved policy (P2842–2852), contradicting S244.

3. **Task 7B, Step 1 — the write proof does not issue SQL to a query endpoint.** It POSTs form data to `/datasette/<db>/-/query` and accepts 400/403/405 (P2985–2995). A nonexistent/GET-only route passes all ten iterations even without `--immutable`.

Datasette is currently absent. The current `py -3` is Python **3.12.8 / SQLite 3.45.3**, not the claimed 3.13.7 / 3.50.4 at P9.

5. **Task 7B, Step 1 — child lifecycle is unsafe.** Terminating the PowerShell wrapper (P2996–2998) does not guarantee termination of its spawned Python/Datasette child on Windows.

6. **Task 8, Step 3 — `STATE.md` routing is under-specified.** The gate requires it in the current worktree (P3309–3311), while Task 1 requires its creation only on `ops` (P78). No step brings the ops-routed file into the work-branch tree without violating or expanding routing.

7. **Task 8, Step 3 — manifest artifacts are self-authorizing.** `validate_manifest()` never compares `artifacts` with the exact spec allowlist (P3182–3196); `validate_files()` trusts whatever paths the manifest names (P3199–3209). Adding an arbitrary artifact to the manifest makes it allowed.

8. **Task 8, Step 3 — subprocess network bypass.** Replacing `socket.socket` affects only the gate process (P3242–3266). Datasette, Git hooks, or any other child process can perform uncounted outbound calls while `external_network_calls` remains zero.

9. **Task 4/6 — raw command-shaped payload values pass.** The validator rejects `@`, `://`, and newlines only (P2073–2084). For example, a shell-like string in `lane`, `label_code`, or an opaque-ID field passes. P1 `_act` rejects it, but the stored boundary is unsafe for later adapters.

10. **Task 8 — sole command differs from the contract.** S914 names `python -m scripts.prospecting.gate --phase P1`; P3408 instructs `py -3 -m ...`. On this host they select an unpinned runtime.

11. **Task 8 — unknown phase can echo raw input.** P3273–3275 prints `args.phase` before calling the PII guard, so arbitrary input can reach stdout.

No undefined imports or advertised function-signature mismatches were found. The Task 2A SQL uses no feature unsupported by SQLite 3.50.4.
