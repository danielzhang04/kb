## Result

HIGH

- `worker/desktopapps.py:157-161` - Desktop detail sanitization is incomplete. A profile such as `AppProfile("x", r"C:\bin\tool.exe?token=secret")` produces `signed executable not found: tool.exe?token=secret`, violating the no-query/token rule. Fix: reuse a single ASCII basename sanitizer that removes query/fragment/argv content before formatting detail.

- `worker/mcp_client.py:436-440,483-498` - Every `_resolve_spec` failure is reported as `not_configured / config entry missing`. Malformed JSON, permission errors, transport import failures, and other resolver faults therefore lie about connector state. A test with malformed Claude JSON would expose this. Fix: classify only missing file/entry failures as `not_configured`; map malformed or unreadable configuration to a closed `error` detail.

- `worker/mcp_client.py:392-415` - Calling `connect()` while a server is already connected overwrites its task and stop-event entries without stopping the first task. `close()` can then leave the original session or child process untracked. The retry test covers only retry-after-failure. Fix: reject concurrent reconnects or stop and await the existing per-server task before replacing it.

- `worker/app.py:550-554`, `worker/desktopapps.py:153-155,396-433`, `ui/app.js:20,1165-1169` - Every visible Settings poll re-runs signed-executable resolution for all profiles, potentially launching up to five PowerShell Authenticode checks every five seconds. Fix: return a cached status snapshot and refresh it through a bounded, explicit or low-frequency background check.
