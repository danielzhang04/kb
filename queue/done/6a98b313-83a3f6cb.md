\## What happened (live, three times, 18:46-19:12 local)
Three consecutive `run`s of the same manifest were each placed by RunPod on the SAME secure-cloud
machine (readiness poll showed `machineHost=qvf79yutw3t2`). On that host `git clone
https://github.com/comfyanonymous/ComfyUI` fails every attempt with
`fatal: could not read Username for 'https://github.com': No such device or address` /
`fatal: expected flush after ref listing` (rc=128) — GitHub answering anonymous git with an auth
challenge, i.e. that egress IP is rate-limited/blocked. The same manifest bootstrapped fine on
other hosts today. The repo URL and tag verify fine from the operator's machine.

\## Fix
1. **Machine-host denylist.** Manifest key `avoid_machine_hosts: [..]` (list of RunPod
   `machine.*` host ids as logged in readiness polls) and `avoid_machine_ids: [..]`. Right after
   create (first GET with `includeMachine=true`), if the pod's machine host/id is listed: log
   `AVOIDED HOST <host> — terminating and recreating (attempt k/N)`, terminate + verify, and
   create again, up to `max_placement_attempts` (default 4). Each avoided pod gets its own
   provisional+settled ledger row (elapsed × ceiling rate). If all attempts land on avoided hosts,
   fail closed with a clear banner (no pod left running).
2. **Auto-learn.** When bootstrap fails with a network-class signature (rc=128 on git, `could not
   read Username`, `Could not resolve host`, curl 6/7/28/35, HTTP 403/429 on HF), record the
   host in `<out>/_harness/bad_hosts.json` AND in a session-wide file
   `%LOCALAPPDATA%/kb-figment-pod/bad_hosts.json` (create dir) with timestamp + reason; the
   next run merges that file into the denylist automatically (entries expire after 24 h).
3. **ComfyUI source fallback.** In the bootstrap `comfy-install` step: after the git retries
   are exhausted, fall back to a tarball: `curl -fL --retry 3
   https://codeload.github.com/Comfy-Org/ComfyUI/tar.gz/refs/tags/<git_ref> | tar -xz` into a
   temp dir and move into `comfyui.root` (no `.git`; write `<root>/.figment-tarball-<ref>` marker;
   a later run on the same root with the marker present skips reinstall). Log which path won.
   Also honour optional `comfyui.source_url` (git) and `comfyui.tarball_url` overrides.
4. Add `"avoid_machine_hosts": ["qvf79yutw3t2"]` to `calibrate/runs/grid-01-zimage.yaml` and
   document the key in `manifest.example.yaml`.
5. Tests: avoided host → terminate+verify+recreate, ledger rows for both pods; all attempts
   avoided → fail closed, no live pod; auto-learn writes and expires; bootstrap script contains
   the tarball fallback after git retries and the marker logic (assert ordering); dry-run of
   grid-01 passes.
