\### Root-cause verdict

The strongest conclusion is a trainer-stage failure during Krea loading, embedding caching, or early steps—not a proven container OOM.

- Upload completed at 16:53:47; the first post-upload 502 appeared at 16:59:26, only 5m39s later.
- The old failure path wrote `_training.failed`, exited, then immediately killed ComfyUI via its EXIT trap. Therefore an unreachable failure marker does not prove the container died.

- Toolkit installation and ComfyUI requirement restoration happen before ComfyUI starts; no live-process package swap occurs.
