   `enrollment`/`delivery` with `logical_key`; business-day cadence math (US Eastern, holidays

   firm collision cap; `next_due_at`; property tests over 200 synthetic enrollments (no two sends
   closer than jitter, never above caps, never outside window).
4. Inbound processor (`campaigner/inbound.py`): the ONLY raw-body reader; classify
   bounce/auto-reply/OOO/human-reply/unsubscribe/wrong-person by headers first then body rules;

   tests per class and for the pause-before-classify ordering.
5. Pre-send recheck + linearization (`campaigner/release.py`): for each due delivery: executor
