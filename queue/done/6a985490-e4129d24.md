  create pod → wait ready (timeout) → bootstrap over SSH (idempotent; never `set -e` on cosmetic
  steps; each step logged with exit code) → submit jobs to ComfyUI's HTTP API on the pod
  (via SSH port-forward or the pod's exposed port — pick what RunPod actually supports today
  and say why) → poll history → download outputs (scp -P / rsync over the SSH port; verify file
  count and sizes after download) → terminate → verify (GET returns absent/404; retry terminate
  up to 5× with backoff; if still alive after retries, exit non-zero with a loud
  `POD STILL RUNNING <id>` line) → write `run.json` (pod id, gpu, timings, $ estimate, job
  results) and append one cost row to `ledgers/cost/figment-<YYYY-MM-DD>.tsv`.
- Terminate MUST run on: success, any exception, KeyboardInterrupt/SIGINT/SIGTERM, timeout of
  `--max-minutes` (hard kill watchdog thread), and bootstrap failure. Use try/finally + signal
  handlers + `atexit`.
- The API key: read once from `os.environ["RUNPOD_API_KEY"]`, held in a request session header
  only; a logging filter redacts it if it ever appears in any string; never written to run.json,
