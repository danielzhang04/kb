\## Architecture

The VM may assemble IDs and display a PII-free summary, but it never receives names, addresses,
message bytes, credentials, or a send capability. The canonical approval scope is staged as the
work-order bytes of a normal kb approval card. The dashboard signs those committed bytes; the
desktop verifier imports the existing kb WebAuthn verifier, acts only on the verifier's pinned
card/result, and never parses public-key material itself.

A batch scope binds the campaign, policy, sorted exact revision/contact pairs, batch hash, mailbox,
T1 tier, permitted window, expiry, and a random parent nonce. Materialization is one transaction.
The first approval uses the parent nonce and later rows use deterministic child nonces derived from
the parent nonce plus the exact item. This preserves the P1 unique approval.nonce contract, makes
replaying the assertion fail the entire transaction, and leaves each send with a separately
consumable nonce. Each row's scope_hash is the canonical hash of its exact send scope.

The T1 executor is the only live-send path. It scans inbound first, refreshes the Gmail thread,
rechecks every bound field and all hooks, compare-and-set claims the delivery, and consumes the
matching approval in the same SQLite transaction immediately before the Gmail adapter call.
Follow-ups continue through P4's draft path. T2, T3, sales, and reply-template automation remain
fail-closed.

def manifest_for_phase(root: Path, phase: str) -> Path:
    if phase == "P1":
        return root / "scripts/prospecting/gate_manifest.json"
    if phase in {"P2","P3","P4","P5","P6"}:
        return root / f"scripts/prospecting/gate_manifest_{phase.lower()}.json"
    raise ValueError("unknown_phase")

def p6_static_errors(root: Path, manifest: Mapping[str, object]) -> tuple[str, ...]:
    errors: list[str] = []
    implementation = [
        root / item for item in manifest["artifacts"]
        if str(item).endswith(".py") and "/tests/" not in str(item).replace("\\","/")
    ]
    combined = "\n".join(path.read_text(encoding="utf-8") for path in implementation)
    for required in P6_REQUIRED_IMPORTS:
        if required not in combined:
            errors.append(f"missing_reuse_import:{required}")
    forbidden = ("cryptography.","ecdsa.","fido2.","webauthn.verify")
    for path in implementation:
        if path.name == "verify.py":
            text = path.read_text(encoding="utf-8")
            for token in forbidden:
                if token in text:
                    errors.append(f"alternate_approval_crypto:{path.name}")
            if "open(credentials_path" in text or "read_text(credentials_path" in text:
                errors.append("p6_reads_credential_material")
    for path in implementation:
        text = path.read_text(encoding="utf-8")
        if "gmail_send" in text and path.name not in {
            "executor.py","t1_release.py","gate.py"
        }:
            errors.append(f"send_surface:{path.name}")
    return tuple(sorted(set(errors)))

def evaluate_p6(
    root: Path,
    manifest: Mapping[str, object],
    evidence: Mapping[str, int],
) -> tuple[str, ...]:
    errors = list(p6_static_errors(root,manifest))
    if manifest.get("criteria") != P6_CRITERIA:
        errors.append("p6_criteria_mismatch")
    for key, expected in P6_CRITERIA.items():
        actual = evidence.get(key)
        if actual != expected:
            errors.append(f"p6_numeric:{key}:{actual}:{expected}")
    if evidence.get("human_webauthn_live_gate",0) != 1:
        errors.append("human_gate_pending:first_t1_batch")
    if evidence.get("human_cadence_commit_gate",0) != 1:
        errors.append("human_gate_pending:cadence_on_main")
    return tuple(errors)
