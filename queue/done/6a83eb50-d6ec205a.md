`https://kb.example.ts.net` was 403'd host-not-allowed: `originHost` uses `new URL(...).host`
(strips default ports) while the request Host header may legally carry the explicit default port
(python urllib does; browsers/curl don't). Any spec-conformant client with explicit :443 is
locked out.
