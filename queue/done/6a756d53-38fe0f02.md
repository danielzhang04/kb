\## Fixes (all in the uncommitted files above)

1. **MAJOR-1 — FIFO block DoS**: `noReparseFiles.posix.ts` `withFile` (~line 205) opens without
   `O_NONBLOCK`; a hostile sibling can plant a FIFO at a control-file name and `openSync(O_RDONLY)`
   blocks the daemon's main thread forever. Fix: OR `flags.nonBlock` into that open, exactly as
   `pathKind` (~line 359) already does — `O_NONBLOCK` is a no-op for regular files; a FIFO then
   opens instantly and `assertSafeRegularFile` rejects it as unsafe-path.
2. **MAJOR-2 — fail-open when /proc absent**: every post-root operation goes through
   `descriptorRoot()` paths; with `/proc` unmounted, opens fail ENOENT → mapped to 'missing' →
   callers like `assertNoRunRecords` (authorizedFailedRunReconciliation.ts:~227) treat a
   never-ran check as "file absent" and PASS vacuously. Fix: at `openPosixNoReparseFileTree`
   entry, probe the descriptor root once (`openDirectory(descriptorRoot())`, close it) and throw
   `NoReparseFileError('unsupported', 'open')` if unusable.
3. **MAJOR-3 — unproven platforms**: selector `noReparseFiles.ts` line ~20 claims darwin/freebsd,
   but `/dev/fd/N/<name>` traversal is unproven there and FreeBSD returns EMLINK (unmapped) for
   O_NOFOLLOW-on-symlink. Fix: narrow the POSIX arm to `process.platform === 'linux'`; leave a
   one-line comment that darwin/freebsd need a proven run + EMLINK mapping before re-adding.
4. **MAJOR-4 — test coverage**: port these from `server/win32/noReparseFiles.test.ts` into
   `noReparseFiles.posix.test.ts` (they translate near-verbatim; junction → symlink):
   (a) hardlink rejection (linkSync a second name; expect unsafe-path);
   (b) deleteFileIfPresent + deleteEmptyDirIfPresent happy + identity coverage;
   (c) assertEmptyDirectory, completeUtf8FromPrefix, appendUtf8IfExact incl. the
       testShortWriteBytesOnce fault-injection case;
   (d) relative-component validation through the tree API (writeUtf8 with [''], ['.'], ['..'],
       ['status','..']);
   plus two POSIX-specific cases: createRoot over a pre-existing symlink component (expect
   unsafe-path), and a FIFO planted at a file name (use `mkfifo` via child_process ONLY inside a
