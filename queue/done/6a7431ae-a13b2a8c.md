\## The finding
`/events` SSE (`server/hub/sse.ts`) is origin-guarded but has NO session gate — every same-origin subscriber receives every frame, pre-signin. Your `publishAttemptIoDelta` ships the full attempt-io entry (`data.entry.line`) in the frame, while W1's REST read of the SAME lines (`GET /api/control/runs/:runRef/attempts/:attemptRef/io`) requires a verified WebAuthn session. Transcript content must never be readable below the session gate. The repo already encodes the right pattern: `publishTailDelta` (`server/hub/bus.ts:83`) ships count+offset only, and the consumer re-tails through the authed surface.

\## Required changes
1. `server/hub/bus.ts`: rename/replace `publishAttemptIoDelta` with `publishAttemptIoSignal(bus, {attemptRef, seq})` → frame `{channel:'control', kind:'attempt-io', data:{attemptRef, seq}}`. NO entry, NO line, NO dir/t fields. Doc-comment states the security rationale (mirror publishTailDelta's comment style).
2. `server/http/surface.ts` wiring: adapt the latch subscription to publish the signal (`{attemptRef: evt.attemptRef, seq: evt.entry.seq}`).
3. `src/lib/useAttemptIo.ts`: frames no longer carry lines.
