\## 2. New findings — money first

N0 — BLOCKER. comfy-install exits 1 on every real manifest; every pod dies after create. runpod_run.py:821. All three bakeoff manifests set comfyui.root: "/workspace" because they do the ComfyUI checkout themselves inside start_command (v0.20.1). The bootstrap generates: `if [ -d /workspace/.git ]; then ... ; elif [ -e /workspace ]; then echo 'ComfyUI root exists but is not a git checkout' >&2; exit 1; else git clone --branch v0.3.76 ... /workspace; fi`. /workspace is the volume mount path and always exists → elif → exit 1 → fail=1 → :829 exits → HarnessError: bootstrap failed. Confirmed by generating the actual script from smoke.yaml. Pod already created and READY, so a smoke run buys a pod, waits up to 900 s, fails deterministically. The v0.3.76-vs-v0.20.1 node-set concern (EmptyFlux2LatentImage, Flux2Scheduler, ModelSamplingAuraFlow) is moot only because the run never gets that far. Fix: single owner of the install; settle the pin.

N1 — Money leak. Empty name-scan treated as proof of absence. :394-397. POST times out after RunPod created a billable pod, list API hasn't surfaced it yet. After 5 attempts (~15 s) the code hits `not ever_discovered and _create_uncertain and name_scan_ok and attempt == self.attempts` → _mark_verified. Output: "termination verified: pod figment-bakeoff-x is absent", deletes: 0, verified=True. result["pod_id"] stays None so :1387 skips the ledger row too. Fix: an empty name scan is never proof; raise PodStillRunning with the pod name and print the status recovery banner; only a 404 on a known id counts as verified.

N2 — An exception in the finally block discards `caught` and kills the recovery banner. :1363-1394. Immortal pod (real PodStillRunning) + a today-dated ledger with an unexpected header → upsert_cost_row raises from the finally, PodStillRunning destroyed, propagated HarnessError carries no pod_id / termination_verified, report()'s getattr(..., True) prints no banner. write_json at :1384 has the same exposure. Fix: wrap ledger/JSON writes in try/except BaseException inside the finally; never displace caught.

N3 — Daily budget guard reads a ledger nobody writes. :684-689, :694-695, :1240, :1250. repo_root() is parents[4], whichever checkout the file lives in. kb-worktrees/figment/ledgers/cost = 5 stale July files; main kb/ledgers/cost = same; the authoritative fleet ledger on ops (kb-worktrees/dashboard-ops) = 83 files. So enforce_daily_budget sums ~$0 regardless of real fleet spend, and rows the harness writes land on a work branch. Secondary: real ops ledgers use ≥5 header shapes (`billing card_id model step usd`, `note usd`, `note requested_model responding_model task usd`, header-less data) so :708 ("usd" not in fieldnames) will hard-refuse once a today-dated fleet file exists. Fix: explicit --ledger-dir/env pointing at the ops worktree, default to it; skip loudly rather than crash on files without usd.

N4 — apply_job never set noise_seed (committed e0dc60c6) — ALREADY FIXED at HEAD 1de5d9d4 via seed_fields. Confirm the check runs in preflight (require_manifest), not after download.

N5 — sys.excepthook replaced at import time and swallows every traceback. :89-96. A plain KeyError prints exactly `KeyError: 'missing-key'` with zero frames; any process importing runpod_run (tests included) loses tracebacks. Unnecessary: test_B1 (tests:605-606) proves redactor.redact() scrubs a full traceback. Fix: install inside main(); emit redacted full traceback.

N6 — Signal handlers can stay masked forever. :211-213. The signal.signal() loop sits outside the try at :214; if SIGTERM install raises after SIGINT was replaced, finally never runs and Ctrl-C is a permanent no-op. Related: close() takes the mask BEFORE self._lock (:341); if the watchdog holds the lock the main thread is un-interruptible for up to teardown_budget_seconds() ≈ 316 s.

N7 — Ledger upsert is a lost-update race on a fixed temp name. :1198-1204. Read-modify-replace with no lock, fixed temp `figment-<date>.tsv.tmp`; two concurrent runs replace each other. Fix: unique temp suffix + O_EXCL lock file, or append-only rows keyed by pod id.

N8 — Recover-by-name sweep: LOW. Name is `figment-bakeoff-<UTC second>-<6 hex>`; exact-name match; only when _create_uncertain. Harden: also require matched pod's creation time ≥ started_utc before deleting.

A PreviewImage (type temp) inflates the count and would scp a nonexistent path. Fix: filter to type == "output".
