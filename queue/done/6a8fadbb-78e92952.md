\### Session contract

After MCP `initialize`, Atlas sends:

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/atlas/session",
  "params": {
    "token": "<operator bearer>",
    "expiresAt": "<ISO timestamp or epoch>"
  }
}
```

The bearer remains in process memory and is injected only as `Authorization: Bearer`. It never enters environment variables, arguments, logs, results, or errors. Expiry or HTTP 401 returns:

```json
{
  "code": "session_required",
  "message": "say: Atlas, unlock kb"
}
```

In `tailnet` mode, requests may omit the bearer so the authenticated transport can provide `kb_session`.
