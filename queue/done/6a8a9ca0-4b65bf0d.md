\# Verdict

**REWORK.** Mandatory launcher, fd-pinning, orphan-safety, and real-oracle requirements are absent or structurally incomplete. Passing tests mostly exercise helpers and fakes.

\## Blockers

1. **Required process interface is missing.** `startLinuxBrokerMain` accepts no CLI arguments, falls back to binding the pathname, and has no `--print-protocol-version` path. [linuxBrokerMain.ts:167](/C:/Users/danie/AppData/Local/kb-codex-dispatch/worktrees/6a8a8c35-07ee12c4/dashboard/server/pty/linuxBrokerMain.ts:167), [linuxBrokerMain.ts:195](/C:/Users/danie/AppData/Local/kb-codex-dispatch/worktrees/6a8a8c35-07ee12c4/dashboard/server/pty/linuxBrokerMain.ts:195). **Fix:** accept exactly `--socket-fd=3`, refuse every other fd/argument, remove pathname fallback, and print exactly `kb-shell-broker/v1`.
2. **Fd pinning is not TOCTOU-safe.** `realpath` and parent checks happen before pathname-based `open`; ancestors are not opened through pinned dirfds, and symlink/shebang/Node/JS/interpreter chains are not pinned. Planned `02770` worktree parents are also rejected as group-writable. [fdPinnedPaths.ts:196](/C:/Users/danie/AppData/Local/kb-codex-dispatch/worktrees/6a8a8c35-07ee12c4/dashboard/server/pty/fdPinnedPaths.ts:196), [fdPinnedPaths.ts:225](/C:/Users/danie/AppData/Local/kb-codex-dispatch/worktrees/6a8a8c35-07ee12c4/dashboard/server/pty/fdPinnedPaths.ts:225), [linuxBrokerMain.ts:141](/C:/Users/danie/AppData/Local/kb-codex-dispatch/worktrees/6a8a8c35-07ee12c4/dashboard/server/pty/linuxBrokerMain.ts:141). **Fix:** traverse with pinned dirfds/openat2-style no-follow semantics, validate exact owner/gid/mode per root, pin every interpreter/entrypoint component, and exercise barrier swaps against production launch.
3. **Crash/orphan safety is missing.** A child is spawned and acknowledged before durable state completes; restart cleanup kills an unverified persisted PID rather than a verified cgroup/process identity. A crash between spawn and persistence leaves an undiscoverable child; PID reuse can kill an unrelated `kb-shell` process. `linuxBrokerServer.ts:319-331`; `linuxBrokerMain.ts:160-162`. **Fix:** contain children before exposure, durably record before ACK, recover through verified cgroup/process identity, and test the crash windows.
4. **Runtime state invalidates itself after 17 sequential sessions.** Receipts are added permanently and not removed on exit, while the loader refuses more than 16. `linuxBrokerServer.ts:325-326,353-361,374-385`; `linuxBrokerMain.ts:43-49`. **Fix:** define bounded durable receipt retention consistent with idempotency and test more than 16 create/exit cycles across restart.
5. **The WSL oracle does not run the broker code.** It launches a separate Python broker at `tests/test_pty_linux_oracle.py:121-220`; fd pinning is a standalone `os.open` demonstration and high-water is a source-substring assertion at `:359-375,399-400`. **Fix:** launch the built JS broker via fd 3, drive its real decoder/launcher/state, and use an actual dashboard fixture process.
6. **The requested opaque recipe-id contract conflicts with W0.** W0 itself carries `recipe` and `relativeCwd` (`dashboard/shared/ptyProtocol.ts:78-79`), and the client forwards both (`linuxBrokerClient.ts:88-91`). The broker accepts arbitrary regex-valid models rather than an approved model table (`fdPinnedPaths.ts:132-160`). **Fix:** resolve W0 first, then use an opaque broker-owned recipe ID plus an approved model/policy mapping.

\## Majors

- **Backpressure is incomplete.** Input over high-water is refused, never paused; output detachment covers PTY data only, while general sends ignore `socket.write(false)`. A malicious slow dashboard can accumulate ACK/error output. `linuxBrokerServer.ts:240-264,334-371`; `linuxBrokerClient.ts:251-269`.
- **Binary input is corrupted.** Accepted bytes are decoded as UTF-8 before `node-pty.write`; e.g. `0xff` becomes the three-byte replacement character. `linuxBrokerMain.ts:131`. Preserve bytes or narrow and document the wire contract.
- **Service identity is not enforced.** Main accepts any effective uid/gid, including root, and derives the expected dashboard uid from the socket owner. `linuxBrokerMain.ts:167-184`. Resolve and require exact `kb-shell`/`kb-dashboard` identities and refuse root/wrong gid.
- **The 26 invalid-vector test is ineffective.** It passes each `{case, frame, ...}` wrapper to the decoder rather than `vector.frame`, so every iteration fails merely because `type` is missing. `brokerProtocol.test.ts:32-36`; `ptyProtocolVectors.ts:101-127`.
- **Epoch tests overclaim.** Client test `:58-70` creates no session or old-epoch frame; server test `:97-110` never asserts `killOrphan` was called. Drain resolves on close ACK and does not establish old-epoch late-exit suppression. `linuxBrokerClient.ts:199-216,273-302`.
- **Probe typing/ownership is widened.** `ProbeResult.reason` is re-declared as `string`, socket uid/gid checks are optional, and tests inject peer identity rather than using production `SO_PEERCRED`. `brokerProbe.ts:14-31,50-60`.
