Winning recipe:

1. Mint a positively described, unoccupied video-local place plate.
2. Author large foreground machinery/props, a deep unobstructed aisle, and an explicit far floor line.
3. Put figure placement last in the prompt.
4. Seed `[STEP‑1 figure A, STEP‑1 figure B, empty place, recurring prop]`.
5. Do not use the distant-pair intermediate.
6. Put exact object counts in the final payload clause, with other surfaces positively described as bare.

The current Forge builder can consume an approved empty `place_anchor`, but cannot derive that intermediate automatically for the same figure-bearing shot. Production adoption therefore needs an upstream empty-place shot or a future builder-owned `empty_place` step.
