\## Before provisional real capture

1. **HIGH — Unknown files are read before rejection.**  
   [pilot-recovery.ps1:243](<C:/Users/danie/Projects/Filesystem-Cleanup/scripts/pilot-recovery.ps1:243>)

   `Get-Manifest` calls `Get-FileRecord`—including SHA-256, ACL, streams, and SACL—for every ordinary file. Therefore `ExtraFile → exit 2` does not establish that the unknown file was not read. A concurrently created sensitive file would be consumed before `Get-SourceBlocks` rejects it.

   Minimal edit in `Get-Manifest`:

   ```powershell
   \# old
   if (-not $c.PSIsContainer -and -not ([int]$c.Attributes -band 0x400)) {
       $m.files[$c.Name] = Get-FileRecord $c.FullName
       $m.totalBytes += $c.Length
   }

   \# new
   if (($KnownNames -ccontains $c.Name) -and
       -not $c.PSIsContainer -and
       -not ([int]$c.Attributes -band 0x400)) {
       $m.files[$c.Name] = Get-FileRecord $c.FullName
       $m.totalBytes += $c.Length
   }
   ```

   This remains safe if an unknown appears between enumeration and manifest construction: only its name/type/attributes are observed.
