1. **HIGH — `scripts/agent_definitions.py:76`** — Definition loading follows symlinks/junctions. Consequently, `agent_factory bump` can modify a frontmatter file outside the repository, while dispatch can read one as a “declaration.” Resolve the canonical path, reject reparse points/symlinks, and require a direct child of `<repo>/agents`; add symlink/junction tests.

2. **HIGH — `scripts/agent_factory.py:306`** — `read_text()` normalizes newlines, then `write_text()` re-emits platform newlines. On Windows, bumping the current mixed-EOL demo definition would alter hundreds of bytes instead of only the version line. Perform a byte-level replacement or use newline-preserving I/O; byte-compare the remainder for LF, CRLF, and mixed-EOL fixtures.

3. **HIGH — `scripts/codex_dispatch.py:686`** — The version is read after `spawn()` finishes, potentially 45 minutes after dispatch began. A definition changed, created, or deleted during execution produces incorrect or fabricated provenance. Capture the validated version before spawning and stamp that immutable value afterward.

4. **MEDIUM — `scripts/eval_trigger.py:175`** — Drift detection checks only whether endpoint versions are equal. EOL-, mode-, or whitespace-only changes falsely warn, while a substantive edit with a version regression such as v3→v2 passes. Three-dot ranges also compare against `A`, not the merge base used by `git diff A...B`. Compare normalized non-version content, require `new_version > old_version`, and resolve the merge base for `...`.

5. **MEDIUM — `dashboard/server/agents/roster.ts:496`** — Python and dashboard defaults are not identical. For example, Python preserves quoted `"2.5"` as a string, while the dashboard converts it to `2.5`; Python rejects YAML boolean `True` to `null`, while the dashboard retains `"True"`. Preserve quoted scalar identity and add cross-port parameterized tests.
