\## 4. The glossiness question

The answer is:

- **(a) Yes—primarily in the generated fills.**
- **(b) No—the downscale is secondary.**
- **(c) Yes—the P6-inverted positive language is the strongest present cause.**

\### Why it is generated, not resized

The native 1678×937 sources already contain L50’s glossy lamp highlight, facial gradient and amber wood bloom; L28 already has its broad aisle ramp; L36 already has modeled paper surfaces. Resizing can thin outlines and smooth micro-hatching, but it cannot invent 100–500 px lighting ramps.

The measurements support that:

- L28 native M2 **0.365** → staged **0.443**; baseline **0.836**.
- L50 native **0.096** → staged **0.122**; baseline **0.275**.

For both, downscale actually makes the flatness metric slightly better, not worse. The glossy structure precedes normalization.

\### Prompt language causing it

Every final prompt begins:

> “flat cel fills enriched with soft light pools and gentle tonal gradients on large surfaces, subtle contact shadows … faint paper-grain surface texture … same high detail density”

See [L27 line 3](C:/Users/danie/kb-worktrees/boss-codex-image-engine/.superpowers/sdd/2026-08-11-codex-image-engine/p8-real-results/p8-staging/_codex/prompts/L27-p8-match-r1.txt:3).

It then repeats:

> “soft light gradients and subtle contact shadows are required; poster-flat minimalism is wrong”

while also saying:

> “every surface is a flat painted fill”

See [L35 line 24](C:/Users/danie/kb-worktrees/boss-codex-image-engine/.superpowers/sdd/2026-08-11-codex-image-engine/p8-real-results/p8-staging/_codex/prompts/L35-p8-match-r2.txt:24).

Shot-specific amplifiers include:

- L27: “pale blue-white sheen.”
- L28: “gentle but plainly visible brightening with feathered edges.”
- L32: “GLOWS INTENSELY,” “strong radial red bloom,” “near-molten red.”
- L35: “wrap sheen” and “wide soft feathered pool.”
- L50: “bright warm cone,” “soft elliptical warm pool,” “highlight rim.”

The P6 diagnosis correctly noticed that the approved Gemini register is not universally poster-flat. But the inversion overshot: localized face, emitter and shrink-wrap modeling became a global instruction to gradient-model large surfaces. The defect is not “Gemini has zero gradients.” It is that Gemini allocates them selectively while P8 distributes them across matte materials.

\## 5. Steelman Daniel

The strongest version is:

> This cannot converge through more prompt levers because the optimization target is not prompt-identifiable. Each whole-frame reroll simultaneously changes room geometry, camera, identity, pose, count, palette, line hierarchy, material finish and lighting. A correction to one clause redraws every region that was already right. The contracts grow, stale facts remain, contradictions accumulate, and unrelated style images exert uncontrolled content and temperature pressure. R1→r2 is already non-monotonic proof: “more precise” prompts regress previously closer poses and objects.

The alternative architecture is preservation-first:

1. Make approved same-place environment plates and in-chain parents structurally mandatory.
2. Never trade them for cross-place narrative “style” frames.
3. Keep W1-approved figure/prop cards, but insert them through localized edit, mask, or deterministic compositing rather than asking for full-frame identity recreation.
4. Use the content-thin registered style tile only after the proper seed-displacement walk.
5. Separate lettering and other exact geometry into localized generation or deterministic composition.
6. Replace one failed clause surgically; never append deltas to contradictory prose.
7. Run the existing fresh-eyes board and stamp/park gate after each batch.
8. If the two-gen native anti-gloss probe still fails, stop prompt iteration. Retain Gemini for final whole-scene rendering and restrict Codex to isolated assets, masked edits, or shot classes it can demonstrably hold.

That architecture can converge because most approved pixels stop being regenerated. The current architecture cannot make the same promise.
