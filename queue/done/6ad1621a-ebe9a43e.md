   Seed a fresh valid generation but omit `d1\b.bin`; retain the correct manifest and digest. Require exit `4`, category `integrity`, exact message `recovery differs from pinned manifest: d1\b.bin|missing`, last step `paths.withinLimits`, `restoreStarted=false`, and no `restore\`.

2. **Occupied restore**

   Seed a valid fresh generation and pre-create `restore\` with a marker whose bytes and identity are recorded. Require exit `6`, category `occupied`, message `restore output is not cleanly absent (probe 0): <generation>\restore`, last step `recovery.verified`, `restoreStarted=false`, and unchanged marker. This covers occupancy without separately repeating `child-report.json` occupancy.

3. **Malformed LX raw buffer**

   In a fresh copied manifest, change `l2`’s LX version from 2, recompute its raw hash and external manifest digest, while leaving recovery untouched. Require exit `3`, category `malformed`, last step `manifest.provenance`, the exact engine diagnostic naming `l2` and the invalid LX version, `restoreStarted=false`, and no output. The exact full diagnostic must be fixed from the reviewed engine literal before execution—not accepted through a loose regex.

   Fresh compact source with an additional non-allowed ADS on one ordinary file. Run the adapted capture.
