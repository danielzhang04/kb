\## Blockers

- **A successful host launch can become an untracked live PTY.** After the receipt resolves, a collision, validation, or disk failure during durable publication falls into the generic catch; the capacity slot is released, but the child is not closed, the pending receipt is not settled, and buffered frames remain attached. - **Controller claim is neither an atomic Run-version CAS nor an exact replay.** `resolveRunVersion` runs before acquiring the PTY document mutation, allowing the Run version to change in between. After a claim, replay accepts either the original or current session revision and returns the current record revision; an unrelated attach/write therefore changes the supposedly idempotent receipt.
